# 🧠 HydroSync AI & Predictive Engine

مرحباً بك في وحدة الذكاء الاصطناعي وتحليل البيانات لمنصة **HydroSync SCADA**.

## 🎯 دورك الأساسي في المشروع:
تطوير وتحسين خوارزميات التنبؤ المناخي واكتشاف الأعطال الميكانيكية للمضخات قبل حدوثها:
1. **Predictive Maintenance (ISO 10816):** تحليل بيانات اهتزاز المضخات وحرارة الملفات لكشف التكهف (Cavitation) وحساب العمر التشغيلي المتبقي (RUL).
2. **Model Predictive Control (MPC):** تحليل بيانات الأقمار الصناعية (Open-Meteo) للتنبؤ بالأمطار وتعليق الري استباقياً لتوفير المياه (UN SDG 6.4).

## 📂 هيكل الملفات:
* `predictive_ai.js`: نقطة الربط الرسمية مع سيرفر المنصة (Node.js).
* إذا كنت تفضل تدريب نماذجك بلغة **Python** (مثل Scikit-Learn أو PyTorch):
  * يمكنك إنشاء مجلد فرعي `notebooks/` أو ملف `model_training.py`.
  * حفظ النموذج النهائي بصيغة (ONNX أو JSON weights) أو كـ Microservice يتم استدعاؤه هنا.

## 📥 المدخلات المتوفرة لك من الحساسات لحظياً:
* `vibrationRms`: قراءة الاهتزاز الحالية بالملم/ثانية.
* `motorTemp`: درجة حرارة المحرك المئوية.
* `forecastHorizon`: مصفوفة توقعات الطقس لـ 24 ساعة قادمة من القمر الصناعي.
